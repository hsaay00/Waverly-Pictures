# Waverly-Pictures

Waverly Pictures refers to an online movie tickets booking portal that is created in order to give users a convenient online booking experience in all San Diego movie theaters. The system consists of a three tier web application that will allow the customers to browse through the available movies, check their schedules, book seats using the provided seating chart, buy five tickets with discounts, and get digital receipts through Email/SMS.
